# Superstore Sales & Forecasting Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze Superstore sales performance, profitability, orders, regional trends, and sales forecasting.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Sales & Business Analytics

## 📈 Dashboard Features

- Total Sales analysis
- Profit and Order performance
- Regional and state-wise analysis
- Sales trend analysis
- Category and product performance
- 15-day sales forecasting
- Interactive filters and slicers
- KPI cards for quick business insights

## 🎯 Key Objectives

- Track overall sales and profitability
- Identify high-performing regions and categories
- Analyze sales trends over time
- Support data-driven business decisions
- Forecast upcoming sales performance
